# Introduction

In this short series of solution to
[the advent of code 2025](https://adventofcode.com/2025/day/1) I want to
demonstrate some of the patterns Haskell (and similar functional programming
languages) has to make life as nice as possible. My hope is to show that
functional programming is not some strange beast, but can have true beauty and
unmatched expressiveness.

> [!WARNING]
>
> While I will try to explain some of the small things one has to think about
> when writing Haskell, I will not give a proper introduction to its syntax.
> **If you are completely unfamiliar with the language this is probably not the
> best place to start.**
